# NOW Assistant 0.3.0-alpha.1 — Windows x64

Versão experimental **Pre-release**, sem assinatura digital. Esta nota descreve o candidato preparado; não afirma que um build Windows foi aprovado antes de sua execução. A release publicada deve incluir BUILD-VALIDACAO.json, ZIP e SHA256SUMS.txt do mesmo candidato testado.

## Novidades

- Interface desktop com chat por texto ligado à NOW Engine autenticada em loopback.
- Comandos locais em português brasileiro e inglês, sem Gemini.
- Sessões temporárias e histórico opt-in criptografado: buscar, retomar, renomear, exportar e excluir.
- NOW Memory separado para preferências consentidas.
- Pacote portátil com Python/Qt embutidos; não exige VS Code ou Python instalados pelo usuário.

## Instalação e requisitos

Baixe o ZIP Windows x64 desta release, confira SHA256SUMS.txt, extraia a pasta inteira e abra NOW-Assistant.exe. Windows 10 x64 é o alvo, com cerca de 8 GB RAM; o runner automático é Windows Server 2022. Mantenha `_internal` ao lado do executável. Consulte LEIA-ME.md dentro do ZIP para detalhes, privacidade e desinstalação.

## Modelo separado e limitações conhecidas

Ollama e pesos Qwen não acompanham o pacote. Para conversas livres, instale Ollama oficial e execute `ollama pull qwen2.5:0.5b`. Sem modelo, hora/data/ajuda e saudações funcionam; outras perguntas mostram indisponibilidade. O build de distribuição não aprova qualidade de inferência nem oito gerações Qwen. A NOW não depende de Gemini.

Voz real, wake word “Now”, bandeja/background, visão, ferramentas de sistema, Android e sincronização ainda não estão implementados. Compatibilidade Windows 10/hardware alvo, acessibilidade, DPI e ACLs precisam de revisão manual. A Alpha não possui Authenticode/instalador assinado. Não ignore políticas do Windows/antivírus.
